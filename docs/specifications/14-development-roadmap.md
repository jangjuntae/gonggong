## MVP

- 회원/역할의 최소 모델과 역할·부서 접근통제
- 상품·규칙 버전, 고객 신청과 자격검증
- 담당자 배정, 보완, 승인·거절 상태 흐름
- 대출 실행, 원리금균등 상환계획과 상환 원장
- 대출 실행 원자성과 기본 감사로그
- 단위·Repository·Service·API 핵심 테스트

## 2차 개발

- 멱등성·동시성 강화, 연체와 이상거래 탐지
- 개인정보 암호화·마스킹과 감사 운영 기능
- 대규모 가상 데이터, 쿼리·인덱스 성능 개선
- 운영 대시보드, Actuator, 구조화 로그와 Docker 배포
