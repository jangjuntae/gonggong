# 문서 안내

프로젝트 문서는 목적에 따라 두 디렉터리로 구분한다.

| 디렉터리 | 역할 |
|---|---|
| [specifications/](specifications/README.md) | 요구사항, 업무 규칙, ERD, 테이블·API 및 품질 정책 명세 |
| [agent-prompts/](agent-prompts/) | 기능 완료, 전체 품질, 트랜잭션·DB, 보안·감사 리뷰 지침 |

명세를 변경할 때는 요구사항, ERD, 테이블과 API 간 영향 범위를 함께 확인한다. 리뷰 문서는 구현 및 검증 결과를 임의로 가정하지 않고 실제 코드와 테스트를 근거로 사용한다.
